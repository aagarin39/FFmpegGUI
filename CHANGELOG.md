# Changelog

Все изменения в проекте FFmpegGUI.

Формат: [Semantic Versioning](https://semver.org/lang/ru/)

## [0.4.0] - 2026-03-20

### Исправлено

- **Гонка потоков при установке FFmpeg** — исправлена проблема, когда окно закрывалось после успешной установки FFmpeg
  - Причина: исключение в `_finish_install()` при обновлении UI из рабочего потока
  - Решение: 
    - `_install_done()` теперь сохраняет параметры в атрибуты объекта перед планированием вызова
    - `_finish_install_safe()` выполняет завершение установки в главном потоке с проверками
    - Добавлена задержка 0.5с для корректной записи файлов FFmpeg на диск
  - Файлы: `src/main_pyqt.py`

### Изменено

- Обновлена документация по потокобезопасности в `AGENTS.md`
- Актуализирован `dist/README.txt` с информацией о версии 0.4.0

## Формат версий

- **MAJOR** — критические изменения, несовместимые с предыдущими версиями
- **MINOR** — новая функциональность, совместимая с предыдущими версиями
- **PATCH** — исправления ошибок, не влияющие на API

## Категории изменений

- **Added** — новые функции
- **Changed** — изменения в существующей функциональности
- **Deprecated** — устаревшие функции (будут удалены в будущем)
- **Removed** — удалённые функции
- **Fixed** — исправления ошибок
- **Security** — исправления уязвимостей
